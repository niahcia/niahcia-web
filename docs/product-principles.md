# Product Principles

## One obvious front door

NIAHCIA should have one polished primary site that is easy for ordinary users to understand.

## But no protocol dependence

The official site must never be required to:
- submit transactions
- discover an agent by ID
- execute an AI job
- retrieve public model metadata
- verify public result commitments
- settle protocol payments

## Fast AI experience

Users should see streaming output as soon as execution begins. Final verification and settlement can happen afterward.

## Transparent trust

Show concrete evidence such as version identity, models, operators, verification policy, permissions, and replication rather than one opaque trust score.

## Non-custodial by default

The website does not hold user private keys or protocol-required balances.
